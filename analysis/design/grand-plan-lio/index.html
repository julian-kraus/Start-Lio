      Agent 規則

      Agent 可以自己做的

      • 向備援供應商詢價、請對方保留貨

        不付款、不下單

      • 設定確認點，追蹤供應商承諾

        例如「4 小時內裝車」，到時間自動去確認

      • 供應商沒回應時寄提醒、打電話

        第一次寄信，第二次打電話

      • 有替代品時，決定不避險

        會列在決策頁並說明原因

      • 付款或正式下單

        一律要人簽，不能開給 agent

      什麼時候避險

      失約機率 × 有風險的數量 × 每單位損失 > 避險成本 → 避險
      • 最低門檻

        避險成本低於退款總額的這個比例才自動提出

      • 守約率計算期間

        用來估計失約機率

      • 備援數量要涵蓋

        缺貨情境的百分位，而不是平均值

      • 每少一套的損失

        沒設定時用該產品的退款金額
